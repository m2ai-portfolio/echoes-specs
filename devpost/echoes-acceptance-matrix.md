## What the evidence may and may not claim

**Supported after passing:** a bounded, original virtual task with working state tracking, contextual next-action guidance, specific correction, within-run interruption recovery, latest-placement undo, clean replay, and truthful completion.

**Not supported by these tests:** physical-brick recognition, real assembly verification, spatial registration to physical objects, structural safety, general intelligence, hands-free usability, device comfort/tracking/latency, or persistence across Preview sessions. A human assertion is not a sensor observation. If any optional perception or model behavior is added, label its inputs and validate it separately; it cannot be used to reinterpret these virtual tests as physical evidence.

## Verification boundaries

Use the established `CapturePanelScreenshotTool`, `RunAndCollectLogsTool`, `InjectPreviewGesture`, `scene-graphql`, and supported LEAF paths. Do not use `QueryRuntimeSceneTool`, `PreviewInteractTool`, `CaptureRuntimeViewTool`, or helper workflows requiring/installing `AiPreviewAgentInspect`. An instruction in a generic build workflow does not override this project restriction. Do not force-close Lens Studio or patch generated cache/package code. These restrictions belong in the actual builder handoff as well as this matrix.

Passing the local tests does not authorize a remote push, public upload, submission, new legal agreement, or change to development history. Keep local-ready, public-distribution-tested, and submitted as distinct states.
